# Eslabong Shiny Reroll

Eslabong의 아레나 클랜 창단 화면에서 일반 용병과 챔피언을 자동으로 다시 뽑고, 캐릭터 좌측 상단의 샤이니 표식을 감지하면 멈추는 Windows용 매크로입니다.

## 주요 기능

- 일반 모드와 챔피언 모드를 시작 전에 GUI에서 선택
- 일반 모드: `R` 키로 용병 3명 자동 리롤
- 챔피언 모드: 챔피언(1번)과 일반 용병(2·3번)을 각각 선택해 탐색
- 챔피언을 좌우 왕복으로 유지하거나 오른쪽 방향키로 계속 변경
- 한쪽 발견 즉시 종료하거나, 발견한 쪽을 고정하고 나머지까지 계속 탐색
- 선택한 설정에 맞춘 평균 기대시간 표시
- 캐릭터 크기와 상하 움직임에 대응하는 상대 좌표 기반 표식 탐지
- 로딩 중인 어두운 직업명을 제외하고 완전히 로드된 화면만 판정
- 샤이니 발견 시 긴 알림음과 최상단 결과 팝업 표시
- 결과 팝업에 샤이니 이미지, 직업명, 슬롯, 리롤 횟수 및 소요 시간 표시
- 두 종류를 모두 찾는 설정에서는 챔피언과 일반 용병 결과 및 통계를 함께 표시
- FHD·QHD·4K 16:9 화면 비율 보정
- 게임 창이 전면이 아니면 자동 중지

## 권장 게임 설정

- 창 모드: `테두리 없는 전체 화면`
- 해상도: `1920 × 1080 (16:9)`
- 창 크기: `100%`
- 렌더러: `DirectX 12`

FHD·QHD·4K의 16:9 해상도를 지원합니다. 울트라와이드와 16:9가 아닌 화면 비율은 지원하지 않습니다.

## 사용법

1. [Releases](../../releases)에서 최신 EXE를 다운로드합니다.
2. Eslabong을 실행하고 아레나 클랜 창단의 캐릭터 선택 화면으로 이동합니다.
3. 매크로 EXE를 실행하고 일반 모드 또는 챔피언 모드를 설정합니다.
4. `F8`을 누르면 탐색을 시작합니다.
5. 설정한 종료 조건을 만족하면 자동으로 멈추며 팝업이 표시됩니다.

단축키:

- `F8`: 시작
- `F10`: 즉시 중지 및 최근 12회 진단 화면 저장
- `F11`: 프로그램 종료

## 챔피언 모드 설정

- `챔피언 탐색`: 1번 슬롯의 챔피언을 검사합니다.
- `일반 용병 탐색`: 2·3번 슬롯의 용병을 검사합니다.
- `왼쪽 → 오른쪽 왕복`: 현재 챔피언 종류를 유지하며 다시 뽑습니다.
- `오른쪽만 반복`: 챔피언 종류를 계속 바꾸며 검사합니다.
- `하나라도 발견하면 전체 종료`: 챔피언 또는 일반 용병 중 먼저 발견한 결과에서 멈춥니다.
- `발견된 쪽만 고정`: 찾은 쪽은 건드리지 않고 나머지 대상도 찾을 때까지 계속합니다.

챔피언 탐색을 끄면 챔피언 리롤 방식은 비활성화됩니다. 발견 후 동작은 챔피언과 일반 용병을 모두 탐색할 때만 선택할 수 있습니다.

## 생성되는 폴더

v24 배포판은 매 리롤 화면을 저장하지 않습니다.

- `found`: 확정된 샤이니 화면
- `rejected_candidates`: 후속 프레임 검사에서 제외된 순간 후보
- `debug_recent`: F10으로 중지했을 때만 최근 12회 화면

## 측정 속도와 기대시간

실제 게임 화면에서 측정한 최근 속도는 다음과 같습니다. PC 성능과 게임 로딩 상태에 따라 달라질 수 있습니다.

- 일반 모드: 약 3.37회/초, 평균 약 8분 15초
- 챔피언만 오른쪽 반복: 약 6.23회/초, 평균 약 13분 23초
- 일반 용병만: 약 4.84회/초, 평균 약 8분 37초
- 챔피언과 일반 용병 동시 탐색: 약 3.98회/초

기대시간은 각 캐릭터의 샤이니 확률을 `1/5000`으로 가정한 평균값이며 실제 결과는 크게 달라질 수 있습니다. 선택한 옵션별 예상값은 프로그램 설정 화면 하단에서 바로 확인할 수 있습니다.

## 주의 사항

- 게임 화면과 직업명이 완전히 로드된 뒤 판정하므로 일시적인 로딩 지연에는 자동으로 대기합니다.
- 보라색 방패형처럼 어두운 표식과 캐릭터에서 떨어진 표식도 상대 위치 및 본체와의 분리 여부로 판정합니다.
- 직업명 표시는 Windows의 로컬 한글 OCR을 사용합니다. OCR에 실패하면 직업명 대신 슬롯 번호가 표시될 수 있습니다.
- 직업명 인식 시 Windows PowerShell을 로컬에서 호출하지만 인터넷으로 화면이나 정보를 전송하지 않습니다.
- 현재 방식은 게임이 전면에 있어야 하며, 다른 창으로 전환하면 안전을 위해 중지합니다.
- 서명되지 않은 개인 제작 EXE이므로 Windows SmartScreen이나 백신이 경고할 수 있습니다. 불안하다면 공개된 소스를 직접 확인하고 빌드하세요.
- 게임 업데이트로 UI 배치나 그래픽이 바뀌면 탐지가 정상적으로 작동하지 않을 수 있습니다.
- 매크로 사용 가능 여부는 게임 운영 정책과 커뮤니티 규칙을 직접 확인하세요.

## 빌드

.NET Framework에 포함된 C# 컴파일러를 사용할 수 있습니다.

```powershell
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /unsafe /optimize+ /target:exe /out:EslabongShinyReroll_v24_MULTI_MODE.exe /r:System.Drawing.dll /r:System.Windows.Forms.dll src\EslabongShinyReroll.cs
```

## 검증 범위

- 실제 사용: QHD 및 4K 16:9
- 축소 화면 검사: FHD 16:9
- 기존 `found` 샤이니 표본 전체 회귀 검사
- 일반 모드와 챔피언 모드의 로딩 완료 및 속도 검사
- 챔피언 단독, 일반 용병 단독, 동시 탐색 및 발견한 쪽 고정 동작 검사

오탐이나 미탐을 발견하면 F10을 누른 뒤 `debug_recent` 폴더의 관련 화면과 함께 Issue로 알려주세요.
