# Eslabong Shiny Reroll

Eslabong의 아레나 클랜 창단 화면에서 용병 3명을 빠르게 다시 뽑고, 캐릭터 좌측 상단의 샤이니 표식을 감지하면 자동으로 멈추는 Windows용 매크로입니다.

## 주요 기능

- `R` 키를 이용한 자동 리롤
- 캐릭터 크기와 위치 변화에 대응하는 상대 좌표 기반 표식 탐지
- 순간적으로 분리되는 장비·팔 등의 오탐을 줄이는 다중 프레임 재확인
- 샤이니 발견 시 알림음과 팝업 표시
- 전체 화면 게임 위에서도 결과 팝업을 최상단에 표시
- 팝업에 샤이니 캐릭터 미리보기, 직업명, 슬롯, 리롤 횟수 및 소요 시간 표시
- FHD·QHD·4K 16:9 화면 비율 보정
- 게임 창이 전면이 아니면 자동 중지

## 권장 게임 설정

- 창 모드: `테두리 없는 전체 화면`
- 해상도: `1920 × 1080 (16:9)`
- 창 크기: `100%`
- 렌더러: `DirectX 12`

울트라와이드와 16:9가 아닌 화면 비율은 지원하지 않습니다.

## 사용법

1. [Releases](../../releases)에서 최신 EXE를 다운로드합니다.
2. Eslabong을 실행하고 아레나 클랜 창단의 용병 선택 화면으로 이동합니다.
3. 매크로 EXE를 실행합니다.
4. `F8`을 누르면 리롤을 시작합니다.
5. 샤이니가 감지되면 자동으로 멈추며 팝업이 표시됩니다.

단축키:

- `F8`: 시작
- `F10`: 즉시 중지 및 최근 12회 진단 화면 저장
- `F11`: 프로그램 종료

## 생성되는 폴더

v23 배포판은 매 리롤 화면을 저장하지 않습니다.

- `found`: 확정된 샤이니 전체 화면
- `rejected_candidates`: 후속 프레임 검사에서 제외된 순간 후보
- `debug_recent`: F10으로 중지했을 때만 최근 12회 화면

## 주의 사항

- 샤이니 확률과 게임 로딩 상황에 따라 장시간 실행될 수 있습니다.
- TURBO 모드는 세 슬롯 변화와 밝은 직업명을 연속 확인하면 0.15초 이후 다음 리롤로 진행합니다. 매우 늦게 로드되는 캐릭터는 놓칠 가능성이 있습니다.
- 분리된 고블린 머리카락과 주술사 머리 조각으로 확인된 오탐을 제외합니다.
- 밝기가 낮은 보라색 방패형 샤이니도 본체와의 분리 여부를 이용해 탐지합니다.
- 직업명 표시는 Windows의 로컬 한글 OCR을 사용합니다. OCR에 실패하면 직업명 대신 슬롯 번호가 표시됩니다.
- 직업명 인식 시 Windows PowerShell을 로컬에서 호출하지만 인터넷으로 화면이나 정보를 전송하지 않습니다.
- 서명되지 않은 개인 제작 EXE이므로 Windows SmartScreen이나 백신이 경고할 수 있습니다. 불안하다면 공개된 소스를 직접 확인하고 빌드하세요.
- 게임 업데이트로 UI 배치나 그래픽이 바뀌면 탐지가 정상적으로 작동하지 않을 수 있습니다.
- 매크로 사용 가능 여부는 게임 운영 정책과 커뮤니티 규칙을 직접 확인하세요.

## 빌드

.NET Framework에 포함된 C# 컴파일러를 사용할 수 있습니다.

```powershell
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /unsafe /optimize+ /target:exe /out:EslabongShinyReroll_v23_TURBO.exe /r:System.Drawing.dll /r:System.Windows.Forms.dll src\EslabongShinyReroll.cs
```

## 검증 범위

- 실제 사용: QHD 및 4K 16:9
- 축소 화면 검사: FHD 16:9
- 샤이니 예시: 태양형 및 번개형
- 실제 100회 연속 리롤 검사: 약 4.9회/초, 마지막 12회 모두 세 캐릭터와 직업명 로드 확인

오탐이나 미탐을 발견하면 F10을 누른 뒤 `debug_recent` 폴더의 관련 화면과 함께 Issue로 알려주세요.
